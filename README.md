# Aarav Das — Portfolio

Personal portfolio site for Aarav Das, robotics engineer and software developer. Built with React, TypeScript, Vite, and Tailwind CSS v4.

## Sections

- **Hero** — intro and key stats
- **About** — quick highlights
- **Experience** — CurieTech AI internship and FRC Team 2367 leadership
- **Projects** — personal robotics and software projects
- **Skills** — categorized tech stack
- **Education** — schools, coursework, and published research
- **Contact** — email and GitHub

Resume content lives in `src/data/resume.ts` — edit that file to update copy without touching components.

## Development

```bash
npm install
npm run dev      # start dev server
npm run build     # type-check and build for production
npm run preview   # preview the production build locally
```

## Deploying

The build output in `dist/` is static and can be deployed to any static host (Vercel, Netlify, GitHub Pages, etc.).
